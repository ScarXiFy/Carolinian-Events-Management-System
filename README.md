# 🏛️ Carolinian Events Management System

A robust, full-stack CRUD web application designed to streamline event management for the Carolinian community. This project demonstrates database integration, responsive UI/UX design, and core backend logic.

## 🚀 Features
- **Full CRUD Functionality:** Seamlessly Create, Read, Update, and Delete event records.
- **Dynamic Data Display:** View event lists in an organized table format.
- **Advanced Sorting:** Rearrange and filter data based on multiple columns for better accessibility.
- **Responsive Design:** A user-friendly interface built with modern HTML5 and CSS3.
- **Secure Database Integration:** Robust MySQL backend connected via PHP.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** PHP
- **Database:** MySQL (via phpMyAdmin)
- **Environment:** XAMPP
